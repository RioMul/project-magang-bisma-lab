=== PENJELASAN MASALAH ===
Alasan mengapa halaman "Edit Website" pada sisi client (URL: /client/website/edit) tidak bisa dibuka (atau hanya menampilkan halaman putih kosong) adalah karena file view-nya, yaitu:
`resources/views/client/website/edit.blade.php`
saat ini dalam keadaan kosong (0 baris kode).

=== STRUKTUR & CONTOH TEMPLATE UNTUK SIMULASI ===
Untuk membuat halaman ini berfungsi sebagai simulasi edit website, kita perlu menambahkan sebuah form yang terhubung dengan Layout Client. Data sementara yang akan di-load sudah disiapkan di dalam `WebsiteController` (business_name, description, phone, address).

Berikut adalah struktur kode yang harus Anda masukkan ke dalam file `resources/views/client/website/edit.blade.php`:

```blade
@extends('layouts.client')

@section('title', 'Edit Website | Client Area')

@section('content')
<div class="mb-6">
    <h1 class="text-2xl font-bold text-slate-800">Pengaturan Website</h1>
    <p class="text-slate-500 text-sm mt-1">Perbarui informasi utama website Anda di sini.</p>
</div>

@if (session('success'))
    <div class="mb-6 p-4 rounded-xl bg-emerald-50 border border-emerald-200 text-emerald-700 flex items-center gap-3">
        <svg class="w-5 h-5" fill="none" viewBox="0 0 24 24" stroke="currentColor" stroke-width="2">
            <path stroke-linecap="round" stroke-linejoin="round" d="M5 13l4 4L19 7"/>
        </svg>
        <span class="font-medium">{{ session('success') }}</span>
    </div>
@endif

<div class="bg-white border border-slate-200 rounded-2xl p-6 shadow-sm">
    <form method="POST" action="{{ route('client.website.update') }}">
        @csrf
        @method('PUT')

        <div class="grid grid-cols-1 gap-6 md:grid-cols-2">
            <!-- Nama Bisnis -->
            <div class="col-span-1 md:col-span-2">
                <label for="business_name" class="block text-sm font-semibold text-slate-700 mb-2">Nama Bisnis / Brand</label>

                    class="w-full px-4 py-2.5 rounded-xl border border-slate-300 focus:border-indigo-500 focus:ring-2 focus:ring-indigo-200 outline-none transition-all"
                    placeholder="Masukkan nama bisnis Anda">
            </div>

            <!-- Deskripsi Singkat -->
            <div class="col-span-1 md:col-span-2">
                <label for="description" class="block text-sm font-semibold text-slate-700 mb-2">Deskripsi Singkat</label>
                <textarea name="description" id="description" rows="4" 
                    class="w-full px-4 py-2.5 rounded-xl border border-slate-300 focus:border-indigo-500 focus:ring-2 focus:ring-indigo-200 outline-none transition-all"
                    placeholder="Ceritakan sedikit tentang bisnis Anda">{{ old('description', $websiteData['description'] ?? '') }}</textarea>
            </div>

            <!-- Nomor Telepon -->
            <div>
                <label for="phone" class="block text-sm font-semibold text-slate-700 mb-2">Nomor WhatsApp / Telepon</label>
                <input type="text" name="phone" id="phone" 
                    value="{{ old('phone', $websiteData['phone'] ?? '') }}"
                    class="w-full px-4 py-2.5 rounded-xl border border-slate-300 focus:border-indigo-500 focus:ring-2 focus:ring-indigo-200 outline-none transition-all"
                    placeholder="Contoh: +62 812 3456 7890">

                    value="{{ old('address', $websiteData['address'] ?? '') }}"

        <div class="mt-8 flex justify-end gap-3">
            <a href="{{ route('dashboard') }}" class="px-5 py-2.5 rounded-xl border border-slate-300 text-slate-700 font-semibold hover:bg-slate-50 transition-all">

                Simpan Perubahan
            </button>
        </div>
    </form>
</div>
```

=== CARA KERJA (SIMULASI) ===
1. Saat halaman dibuka (metode `edit`), `WebsiteController` akan mengirim variabel `$websiteData` (data dummy/sementara) ke tampilan Blade.
2. Data dummy ini di-load ke dalam setiap kolom input sebagai nilai default (menggunakan properti `value`).
3. Client/User bisa mengubah data tersebut.
4. Ketika menekan "Simpan Perubahan", form akan dikirim via metode `PUT` ke URL `/client/website`.
5. Di controller, fungsi `update()` akan merespons form tersebut dan mengembalikan client kembali ke halaman sebelumnya dengan membawa session pesan "Pengaturan website berhasil disimpan."
6. Pesan tersebut akan ditangkap oleh `@if (session('success'))` di view, lalu memunculkan banner notifikasi sukses berwarna hijau.
